# DeutschGrammatikMeister — German Grammar Reference

A static, German-language reference site explaining German grammar (cases, verb conjugation, adjective declension, sentence structure and more) to learners, with a full A1–C1 rule catalog and interactive exercises.

🇩🇪 German version: [README.de.md](README.de.md)

## What it does

- **Startseite:** landing page with a visual hero (illustrated Kasus/Präsens cards), a search box, level cards (A1–C1) and topic sections (Nomen, Verben, Adjektive, Satzbau, …).
- **Level pages (`a1.html` … `c1.html`):** 58 grammar rules (11 A1, 12 A2, 13 B1, 12 B2, 10 C1), each with a German explanation, examples, and an exercise with a revealable solution.
- **Glossar:** short definitions of the grammar terms used on the page.
- **Ressourcen:** links to Deutsche Welle, the Goethe-Institut, and Canoonet.
- **Essay Tutor integration:** `regeln.json` is the machine-readable rule catalog; the Essay Tutor copies it so a detected grammar error can deep-link to the matching rule here (rule ids are stable — never rename them).

## Tech stack

Plain HTML and CSS, no framework. The level pages and `regeln.json` are generated by a small Python build script; the search index is built with Pagefind.

## Running it

Serve the folder with any static file server:

```bash
npx serve .
```

## Build

Level pages are generated from the rule data — do not edit `a1.html` … `c1.html` by hand:

```bash
python3 tools/build.py && npx pagefind --site . --glob "*.html" --output-path pagefind
```

`regeln/a1.json … c1.json` hold the 58 grammar rules (German explanations, examples, exercises with solutions). `tools/build.py` generates `a1.html … c1.html` and `regeln.json` (rule catalog with stable ids that the Essay Tutor links to). Never rename a rule id; add new rules instead. Then rebuild the search index. The explanations are AI-drafted and should be reviewed by a German teacher.

## Search

The search box uses [Pagefind](https://pagefind.app) (static index, no server). After editing any HTML page, re-run the build command above and commit the `pagefind/` folder.

## Design notes

The site was visually redesigned: a card-based layout with per-level accent colors (A1 green, A2 cyan, B1 blue, B2 violet, C1 pink), illustrated hero art drawn in inline SVG/CSS, and a responsive layout that works from ~360 px phones up to wide desktops. The level pages have a sticky table-of-contents rail on desktop that collapses into a horizontal scroller on mobile.

## Notes

The original source was a single Turkish-language landing page with three teaser cards linking to `#` (no real content, all nav links dead). It was rewritten as a German grammar reference with real rules, a glossary, and a resources section before publishing. An unused 3.2 MB photo of a German textbook page (copyrighted, not referenced in the code) was excluded.
